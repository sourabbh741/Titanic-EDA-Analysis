# Titanic-EDA-Analysis
Exploratory Data Analysis (EDA) on Titanic dataset using Python with statistical insights and visualizations (heatmap, Pair plot, histograms)
# Titanic EDA Analysis 🚢

## 📌 Objective
Perform exploratory data analysis on Titanic dataset to understand patterns and relationships.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 🔍 Steps Performed
1. Summary statistics analysis
2. Histogram for distribution
3. Boxplot for outliers
4. Correlation heatmap
5. Pairplot for relationships
6. Countplot for survival analysis

## 📊 Key Insights
- Higher fare passengers had better survival chances
- Age distribution shows slight skewness
- Fare contains outliers
- Survival is imbalanced
